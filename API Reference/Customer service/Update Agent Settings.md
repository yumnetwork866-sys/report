# Path: /customer_service/202309/agents/settings
# Method: [PUT]
# Function Description
Use this API to set whether the shop owner's customer service account can accept auto-assigned chats. The authenticated shop owner can update only their own setting; customer service subaccounts are not supported in this API version. Set `can_accept_chat` to `true` to accept auto-assigned chats.

# Request Body Parameters
| Properties <!-- width:110px --> | Type <!-- width:90px --> | Require <!-- width:90px --> | Sample <!-- width:254px --> | Properties description <!-- width:254px --> |

| can_accept_chat | bool | Y | true | Whether the shop owner's customer service account can accept auto-assigned chats. |

* `true`: The agent receives auto-assigned chats and can also manually select chats to respond to.
* `false`: The agent receives only manually assigned chats.

For a shop with only one customer service agent, set this field to `true`; `false` is rejected. When using the IM API, `true` is recommended. |
