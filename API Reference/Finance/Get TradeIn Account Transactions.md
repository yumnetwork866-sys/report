# Path: /finance/202609/account_transactions
# Method: [GET]
# Function Description
Retrieves account transaction records for the currently authorized TradeIn supplier.
The supplier identity and associated seller identity are resolved from the authorization context. The caller cannot specify seller_id.
Only account transactions generated by the TradeIn business are returned.
