# Path: /product/202407/sizecharts/search
# Method: [POST]
# Function Description
Retrieve size charts that a seller has created.

---

# Request Body Parameters
| Properties <!-- width:110px --> | Type <!-- width:90px --> | Require <!-- width:90px --> | Sample <!-- width:254px --> | Properties description <!-- width:254px --> |

| ids | []string | N | ["7362027385890244398"] | Filter size charts by size chart template IDs. |
| Max: 50 IDs |  |  |  |  |
| keyword | string | N | size chart | Filter size charts by size chart template name or by key words in the template name. |
| Keyword searches do not return PRODUCT_SCOPED size charts because they do not have a template name. |  |  |  |  |
| If both ids and keyword are provided, ids takes priority. |  |  |  |  |
|  |  |  |  |  |
| size_chart_mode | string | N | REUSABLE_TEMPLATE | Filter size charts by usage mode. Possible values: REUSABLE_TEMPLATE: A size chart template that can be reused across multiple products. ```json
