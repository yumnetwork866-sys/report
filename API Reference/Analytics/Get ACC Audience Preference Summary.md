# Path: /analytics/202610/acc/preferences/summary
# Method: [GET]
# Function Description
Retrieve ACC audience preference summaries for products, livestreams, videos, and photo posts for the selected brand, audience segment, scope, and reporting window.

---

| trend_days | int | N | 30 | Number of calendar days in the reporting window, including its end date. Supported values: 7, 14, 30. Defaults to 30 when omitted or set to 0. |
| audience_type | string | Y | CONVERSION | Audience segment to analyze. Supported values: SHOP_NON_EXPOSED, SHOP_CLICKED_NOT_PURCHASED, CONVERSION, NEW_CONVERSION, REPEAT_CONVERSION, DTC_NEW_CONVERSION, DTC_REPEAT_CONVERSION. Segment definitions: SHOP_NON_EXPOSED means people not exposed to the shop; SHOP_CLICKED_NOT_PURCHASED means people who clicked the shop without purchasing; CONVERSION means people who completed a purchase; NEW_CONVERSION means first-time shop buyers; REPEAT_CONVERSION means repeat shop buyers. DTC_NEW_CONVERSION and DTC_REPEAT_CONVERSION select the corresponding DTC new-conversion and repeat-conversion cohorts. ACC, AWARENESS, CONSIDERATION, and the DRC-prefixed values are not supported by the preference APIs. |
| scope | string | N | MY_SHOP | Scope of the preference data. Supported values: MY_SHOP for shop-level data; MARKET for market-level data. Defaults to MY_SHOP when omitted or blank. |
