# Path: /analytics/202610/acc/penetration
# Method: [GET]
# Function Description
Retrieve viewed, clicked, and ordered audience counts and penetration ratios for a brand over the selected reporting window.
Use brand_id and industry_id from the same brands[] record returned by Get ACC Brands (GET /analytics/202610/acc/brands) for the current shop. Select the initial audience with audience_type; account_type and form filter the reported segments.
