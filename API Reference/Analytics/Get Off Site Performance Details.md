# Path: /analytics/202610/off_site/details
# Method: [GET]
# Function Description
Retrieve paginated weekly off-site performance details for videos, LIVE sessions, or products, including GMV and off-site effect metrics.
If the report for the requested pixel and attribution setting is unavailable, results may use the shop-level report with VIEW_14D attribution. If neither report is available, no content records are returned.
