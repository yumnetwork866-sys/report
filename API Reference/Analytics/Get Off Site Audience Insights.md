# Path: /analytics/202610/off_site/insights
# Method: [GET]
# Function Description
Compare weekly on-site and off-site attributed customer audience distributions.
Lists use labels from the TikTok Shop customer distribution. Label filtering and top-10 limits mean that the returned percentages may not sum to 100%.
If the report for the requested pixel and attribution setting is unavailable, results may use the shop-level report with VIEW_14D attribution. Empty distributions can indicate unavailable report data and do not necessarily mean that the shop had no customers.
