# Path: /analytics/202610/acc/preferences
# Method: [GET]
# Function Description
Get a paginated ranking of products, live streams, videos, or photo posts preferred by the selected ACC audience for a brand.
Use `entity_type` to choose the ranking. Each item contains its rank, entity information and preference metrics; `entity_detail` varies by entity type. Select the analysis window with `date` and `trend_days`, and use `scope` to choose shop-level or market-level results. To retrieve more results, pass the returned `page_token` as `page_token` in the next request.
